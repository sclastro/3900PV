fx-3900PV 模擬器

課堂示範用。可用滑鼠按鍵，亦可用鍵盤輸入數字、+ - * /、Enter（=）、Esc（AC）、Backspace（C）、s（SHIFT）、m（MODE）。

按鍵記錄

目前模式鍵義

MODE 對照

MODE 0COMP　一般計算
MODE 1SD　　標準差
MODE 2LR　　線性迴歸
MODE 3BASE　數制運算
MODE 4／5／6DEG／RAD／GRA
MODE 7 nFIX　固定 n 位小數
MODE 8 nSCI　n 位有效數字
MODE 9 1／2NORM 1／NORM 2

預設 NORM 1：絕對值小於 10⁻² 即以指數顯示（例如 1÷1000 顯示 1. ×10⁻⁰³）。要看到 0.001，按 MODE 9 2 轉 NORM 2。

非官方模擬器。鍵盤佈局、MODE 編號與部分 SHIFT 位置屬按 Casio 同期機種慣例重建，未逐鍵核對實機；詳見 README.md 的取捨說明。
