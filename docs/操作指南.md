# fx-3900PV 操作指南（課堂用）

本文的按鍵序列可直接在模擬器上照按，示例後的數值即模擬器實際顯示的結果。方括號表示按鍵，例如 `[SHIFT] [x²]` 即先按 SHIFT 再按 x² 鍵（該鍵橙色標示為 √）。

> 提醒：鍵盤佈局與 MODE 編號屬按 Casio 同期機種慣例重建，未逐鍵核對實機，詳見 `README.md`。

## 一、基本觀念

**函數為後置輸入。** 先按數值，再按函數鍵：求 sin 35° 是按 `3` `5` `[sin]`，不是先按 sin。這是 VPAM 之前機種的做法，亦是本機與後來 fx-3650P、fx-3950P 等雙行機種最大的分別。

**運算次序是真代數次序。** 按 `2` `[+]` `3` `[×]` `4` `[=]` 得 14，不是 20。按下 `[×]` 的一刻顯示 `3.`——因為 `+` 的優先次序低於 `×`，`2＋3` 未收斂；若按 `2` `[×]` `3` `[+]`，按下 `[+]` 時就會顯示 `6.`。這一點很值得在課堂上示範，學生就明白「顯示屏中途變咗嘅數字」是什麼。

**AC 與 C 的分別。** `[AC]` 清除整條算式與顯示，但保留記憶、模式與統計資料；`[C]` 只清除目前輸入的數值，可在按錯數字時原地改正。

**錯誤狀態。** 顯示 `-E-` 並亮起 E 標記時，只有 `[AC]` 或 `[C]` 能解除。

## 二、MODE 對照

| 按鍵 | 作用 |
| --- | --- |
| `[MODE] 0` | COMP　一般計算 |
| `[MODE] 1` | SD　　單變數統計 |
| `[MODE] 2` | LR　　線性迴歸 |
| `[MODE] 3` | BASE　數制運算 |
| `[MODE] 4 / 5 / 6` | DEG／RAD／GRA |
| `[MODE] 7 n` | FIX　固定 n 位小數 |
| `[MODE] 8 n` | SCI　n 位有效數字 |
| `[MODE] 9 1 / 2` | NORM 1／NORM 2 |

### 為何 1÷1000 顯示成 `1. ×10⁻⁰³`

預設為 NORM 1：絕對值小於 10⁻² 就轉指數顯示。按 `[MODE] 9 2` 轉 NORM 2，門檻降至 10⁻⁹，同一條式便顯示 `0.001`。學生第一次見到指數顯示多數會以為計錯，宜及早講清楚。

## 三、一般計算示例

| 題目 | 按鍵 | 顯示 |
| --- | --- | --- |
| 2＋3×4 | `2 [+] 3 [×] 4 [=]` | `14.` |
| (2＋3)×4 | `[(] 2 [+] 3 [)] [×] 4 [=]` | `20.` |
| 10 sin 35° | `1 0 [×] 3 5 [sin] [=]` | `5.735764364` |
| 10 000×1.05³ | `1 0 0 0 0 [×] 1 . 0 5 [xʸ] 3 [=]` | `11576.25` |
| 10! | `1 0 [SHIFT] [x⁻¹]` | `3628800.` |
| ⁵√32 | `5 [SHIFT] [xʸ] 3 2 [=]` | `2.` |
| 850 減 15% | `8 5 0 [−] 1 5 [SHIFT] [=]` | `722.5` |
| 6.02×10²³（SCI 4 位） | `[MODE] 8 4` `6 . 0 2 [EXP] 2 3 [=]` | `6.020 ×10²³` |

百分比鍵是 `[SHIFT] [=]`，本身兼具 `=` 的作用：`A [+] B [SHIFT][=]` 是 A 加 B%、`A [÷] B [SHIFT][=]` 是 A 佔 B 的百分比。例如毛利率：`[MODE] 7 1`（固定 1 位小數）後按 `1 2 0 0 [÷] 4 0 0 0 [×] 1 0 0 [=]` 得 `30.0`。

括號最多 6 層，LCD 左方會顯示現時層數；按 `[=]` 時未關的括號會自動補回。

## 四、度分秒

輸入 12°34′56″：`1 2 [°’”] 3 4 [°’”] 5 6 [°’”]`，顯示 `12°34’56”`，內部值為 12.582222…，可直接參與運算。

反過來把十進位度數化為度分秒：輸入 `4 5 . 3 7 5` 後按 `[SHIFT] [°’”]`（橙色 ←），顯示 `45°22’30”`。

## 五、SD 模式：平均數與標準差

`[MODE] 1` 入 SD 模式。每輸入一個數值按一次 `[DT]`；相同數值可用 `x [×] 次數 [DT]` 一次過輸入，亦可用 `x [SHIFT][,] 次數 [DT]`（`,` 是 `)` 鍵的 SHIFT 功能）。輸入錯了按 `[SHIFT][MR]`（DEL）刪去上一筆，按 `[SHIFT][DT]`（CL）清除全部。

**示例**：測驗分數 65、70、70、75、80、85。

```
[MODE] 1
6 5 [DT]
7 0 [×] 2 [DT]
7 5 [DT]   8 0 [DT]   8 5 [DT]
```

| 要求 | 按鍵 | 結果 |
| --- | --- | --- |
| n（資料個數） | `[SHIFT] 1` | `6.` |
| Σx | `[SHIFT] 2` | `445.` |
| Σx² | `[SHIFT] 3` | `33275.` |
| x̄（平均數） | `[SHIFT] 4` | `74.16666667` |
| xσn（總體標準差） | `[SHIFT] 5` | `6.718548124` |
| xσn−1（樣本標準差） | `[SHIFT] 6` | `7.359800722` |

DSE 數學必修部分用的是 σn（總體標準差）；分不清 σn 與 σn−1 是學生的常見失分位，可即場用同一組資料按出兩個數比較。

## 六、LR 模式：線性迴歸

`[MODE] 2` 入 LR 模式。每對資料按 `x [SHIFT][,] y [DT]`。

**示例**：廣告費（千元）與銷售額（萬元）：(1, 30)、(2, 45)、(3, 55)、(4, 70)。

```
[MODE] 2
1 [SHIFT][,] 3 0 [DT]
2 [SHIFT][,] 4 5 [DT]
3 [SHIFT][,] 5 5 [DT]
4 [SHIFT][,] 7 0 [DT]
```

| 要求 | 按鍵 | 結果 |
| --- | --- | --- |
| n | `[SHIFT] 1` | `4.` |
| A（截距） | `[SHIFT] 7` | `17.5` |
| B（斜率） | `[SHIFT] 8` | `13.` |
| r（相關係數） | `[SHIFT] 9` | `0.997054486` |
| ŷ（x＝5 時的估計值） | `5 [SHIFT] [x²]` | `82.5` |
| x̂（y 已知時反推 x） | `y [SHIFT] [x⁻¹]` | — |

即迴歸方程為 y ＝ 17.5 ＋ 13x。另有 `Σy`（`[SHIFT] 0`）、`Σy²`（`[SHIFT] ·`）、`Σxy`（`[SHIFT] EXP`）及 ȳ、yσn、yσn−1（在 `log`、`ln`、`sin` 鍵的 SHIFT 位，見側欄鍵義表）。

## 七、BASE 模式：數制運算（ICT 用）

`[MODE] 3` 入 BASE 模式，預設 DEC。四個基數以 SHIFT 切換：`[SHIFT][x⁻¹]`＝DEC、`[SHIFT][x²]`＝HEX、`[SHIFT][xʸ]`＝BIN、`[SHIFT][log]`＝OCT。切換基數只改顯示方式，數值不變——這正好用來示範同一個數的不同表示法。

十六進位的 A–F 直接由 `x⁻¹` `x²` `xʸ` `log` `ln` `sin` 六個鍵輸入（模式一轉，鍵面標籤即變成 A–F）。

**示例**：202₁₀ 轉二進位與十六進位

```
[MODE] 3   2 0 2
[SHIFT][xʸ]   →  11001010
[SHIFT][x²]   →  CA
```

**位元運算**：F0₁₆ AND 3C₁₆

```
[SHIFT][x²]（轉 HEX）  F 0  [SHIFT][sin]（and）  3 C  [=]   →  30
```

`or`、`xor`、`xnor` 分別在 `cos`、`tan`、`hyp` 的 SHIFT 位，`Not` 在 `°’”`、`Neg` 在 `π`。負數以 32 位二補數表示：DEC 下輸入 `1 [+/−]` 再轉 HEX，顯示 `FFFFFFFF`。除法為整數運算，會截去小數：`7 [÷] 2 [=]` 得 `3`。

## 八、記憶

`[Min]` 把顯示值存入獨立記憶 M；`[M+]` 加入 M（會先完成待處理的算式）；`[SHIFT][M+]` 為 M−；`[MR]` 讀回 M。M 不為零時 LCD 亮起 M。

常數記憶 K：`[SHIFT][Min]`（Kin）存入，`[SHIFT][MR]`（Kout）讀回，適合把同一個系數（例如稅率、匯率）反覆代入。

## 九、課堂小提示

用右側「按鍵記錄」逐鍵投影，學生跟按時不會漏步；示範完一題按「清除記錄」再開始下一題。切換模式時，鍵面的橙色 SHIFT 標籤會即時改變，正好用來說明「同一個鍵在不同模式下做不同的事」——這是學生用實機時最常撞板的地方。
