# fx-3600Pv 操作指南（課堂用）

本文的按鍵序列可直接在模擬器上照按，示例後的數值即模擬器實際顯示的結果。方括號表示按鍵，例如 `[SHIFT] [√]` 即先按 SHIFT 再按 √ 鍵（該鍵上方橙字為 x²）。

> 提醒：鍵位依實機照片重建，但統計變數的讀取方式與 LR 資料輸入格式未能在照片中核實，詳見 `README.md`。

## 一、基本觀念

**函數為後置輸入。** 先按數值，再按函數鍵：求 sin 35° 是按 `3` `5` `[sin]`，不是先按 sin。這是 VPAM 之前機種的做法，亦是本機與後來雙行機種最大的分別。

**運算次序是真代數次序。** 按 `2` `[+]` `3` `[×]` `4` `[=]` 得 14，不是 20。按下 `[×]` 的一刻顯示 `3.`——因為 `+` 的優先次序低於 `×`，`2＋3` 未收斂；若按 `2` `[×]` `3` `[+]`，按下 `[+]` 時就會顯示 `6.`。這一點很值得在課堂上示範，學生就明白「顯示屏中途變咗嘅數字」是什麼。

**AC 與 C 的分別。** `[AC]` 清除整條算式與顯示，但保留記憶、模式與統計資料；`[C]` 只清除目前輸入的數值，可在按錯數字時原地改正。`[SHIFT][AC]`（KAC）另外清除常數記憶 K 與統計記憶。

**錯誤狀態。** 顯示 `-E-` 並亮起 E 標記時，只有 `[AC]` 或 `[C]` 能解除。

## 二、MODE 對照

機身液晶下方印住兩行對照，模擬器亦照樣畫出：

| 按鍵 | 作用 | | 按鍵 | 作用 |
| --- | --- | --- | --- | --- |
| `MODE ·` | RUN　一般計算 | | `MODE 4` | DEG |
| `MODE EXP` | LRN　程式輸入（未實作） | | `MODE 5` | RAD |
| `MODE 0` | BASE-N　數制運算 | | `MODE 6` | GRA |
| `MODE 1` | ∫dx　積分（未實作） | | `MODE 7` *n* | FIX |
| `MODE 2` | LR　線性迴歸 | | `MODE 8` *n* | SCI |
| `MODE 3` | SD　標準差 | | `MODE 9` `1`／`2` | NORM 1／2 |

### 為何 1÷1000 顯示成 `1. ×10⁻⁰³`

預設為 NORM 1：絕對值小於 10⁻² 就轉指數顯示。按 `[MODE] 9 2` 轉 NORM 2，門檻降至 10⁻⁹，同一條式便顯示 `0.001`。學生第一次見到指數顯示多數會以為計錯，宜及早講清楚。

## 三、一般計算示例

| 題目 | 按鍵 | 顯示 |
| --- | --- | --- |
| 2＋3×4 | `2 [+] 3 [×] 4 [=]` | `14.` |
| (2＋3)×4 | `[[(] 2 [+] 3 [)]] [×] 4 [=]` | `20.` |
| 10 sin 35° | `1 0 [×] 3 5 [sin] [=]` | `5.735764364` |
| 10 000×1.05³ | `1 0 0 0 0 [×] 1 . 0 5 [xʸ] 3 [=]` | `11576.25` |
| 10! | `1 0 [SHIFT] [)]]` | `3628800.` |
| ⁵√32 | `5 [SHIFT] [xʸ] 3 2 [=]` | `2.` |
| ∛27 | `2 7 [SHIFT] [+/−]` | `3.` |
| 850 減 15% | `8 5 0 [−] 1 5 [SHIFT] [=]` | `722.5` |
| ⁴⁹C₆（六合彩注數） | `4 9 [SHIFT] [÷] 6 [=]` | `13983816.` |

百分比鍵是 `[SHIFT] [=]`，本身兼具 `=` 的作用：`A [+] B [SHIFT][=]` 是 A 加 B%、`A [÷] B [SHIFT][=]` 是 A 佔 B 的百分比。例如毛利率：`[MODE] 7 1`（固定 1 位小數）後按 `1 2 0 0 [÷] 4 0 0 0 [×] 1 0 0 [=]` 得 `30.0`。

括號最多 6 層，LCD 左方會顯示現時層數；按 `[=]` 時未關的括號會自動補回。

## 四、分數 a b/c

`[a b/c]` 是分隔鍵：`2 [a b/c] 3` 是 ⅔，`3 [a b/c] 1 [a b/c] 2` 是 3½。顯示以 `⌐` 分隔。

```
2 [a b/c] 3 [+] 3 [a b/c] 4 [=]   →  1⌐5⌐12   （即 1 又 5/12）
再按 [SHIFT][a b/c]（d/c）        →  17⌐12    （假分數）
再按 [a b/c]                      →  1.416666667（小數）
```

即係話 `a b/c` 在沒有輸入中的時候，是分數與小數的切換鍵；`d/c` 則是帶分數與假分數的切換。總位數超過 10 位時會自動改以小數顯示。

## 五、度分秒

輸入 12°34′56″：`1 2 [°’”] 3 4 [°’”] 5 6 [°’”]`，顯示 `12°34’56”`，內部值為 12.582222…，可直接參與運算。

反過來把十進位度數化為度分秒：輸入 `4 5 . 3 7 5` 後按 `[SHIFT] [°’”]`（橙色 ←），顯示 `45°22’30”`。

## 六、SD 模式：平均數與標準差

`[MODE] 3` 入 SD 模式。每輸入一個數值按一次 `[RUN]`（鍵下印住 DATA）；相同數值可用 `x [×] 次數 [RUN]` 一次過輸入。輸入錯了按 `[SHIFT][RUN]`（DEL）刪去上一筆，按 `[SHIFT][AC]`（KAC）清除全部。

**示例**：測驗分數 65、70、70、75、80、85。

```
[MODE] 3
6 5 [RUN]
7 0 [×] 2 [RUN]
7 5 [RUN]   8 0 [RUN]   8 5 [RUN]
```

| 要求 | 按鍵 | 結果 |
| --- | --- | --- |
| n（資料個數） | `[SHIFT] 3` | `6.` |
| Σx | `[SHIFT] 2` | `445.` |
| Σx² | `[SHIFT] 1` | `33275.` |
| x̄（平均數） | `[Kout] 1` | `74.16666667` |
| xσn（總體標準差） | `[Kout] 2` | `6.718548124` |
| xσn−1（樣本標準差） | `[Kout] 3` | `7.359800722` |

記法很直接：**數字鍵下方左邊那個標籤用 `Kout` 叫出，右邊那個用 `SHIFT` 叫出**。DSE 數學必修部分用的是 σn（總體標準差）；分不清 σn 與 σn−1 是學生的常見失分位，可即場用同一組資料按出兩個數比較。

## 七、LR 模式：線性迴歸

`[MODE] 2` 入 LR 模式。每對資料按 `x [×] y [RUN]`。

**示例**：廣告費（千元）與銷售額（萬元）：(1, 30)、(2, 45)、(3, 55)、(4, 70)。

```
[MODE] 2
1 [×] 3 0 [RUN]
2 [×] 4 5 [RUN]
3 [×] 5 5 [RUN]
4 [×] 7 0 [RUN]
```

| 要求 | 按鍵 | 結果 |
| --- | --- | --- |
| n | `[SHIFT] 3` | `4.` |
| A（截距） | `[Kout] 7` | `17.5` |
| B（斜率） | `[Kout] 8` | `13.` |
| r（相關係數） | `[Kout] 9` | `0.997054486` |
| ŷ（x＝5 時的估計值） | `5 [Kout] [)]]` | `82.5` |
| x̂（y＝82.5 時反推 x） | `8 2 . 5 [SHIFT] [)]]` | `5.` |
| Σxy | `[SHIFT] 6` | `565.` |

即迴歸方程為 y ＝ 17.5 ＋ 13x。另有 ȳ、yσn、yσn−1（`Kout` 4／5／6）與 Σy²、Σy（`SHIFT` 4／5）。

## 八、BASE-N 模式：數制運算（ICT 用）

`[MODE] 0` 入 BASE-N 模式，預設 DEC。基數鍵：`[DEC]`、`[HEX]`，以及它們的 SHIFT 功能 `[BIN]`、`[OCT]`。切換基數只改顯示方式，數值不變——這正好用來示範同一個數的不同表示法。

十六進位的 A–F 就在 `+/−`、`°’”`、`hyp`、`sin`、`cos`、`tan` 一整行（模式一轉，鍵面標籤即變成 A–F）。

**示例**：202₁₀ 轉二進位與十六進位

```
[MODE] 0   2 0 2
[SHIFT][DEC]（BIN）  →  11001010
[HEX]                →  CA
```

**位元運算**：F0₁₆ AND 3C₁₆

```
[HEX]  [F] 0  [SHIFT][√]（AND）  3 [C]  [=]   →  30
```

`OR`、`XOR`、`XNOR` 分別是 `log`、`ln`、`xʸ` 的 SHIFT 功能，`NOT` 是 `ENG` 的、`NEG` 是 `+/−` 的。負數以 32 位二補數表示：DEC 下輸入 `1` 再按 `[SHIFT][+/−]`（NEG），轉 HEX 顯示 `FFFFFFFF`。除法為整數運算，會截去小數：`7 [÷] 2 [=]` 得 `3`。

## 九、記憶

`[SHIFT][MR]`（Min）把顯示值存入獨立記憶 M；`[M+]` 加入 M（會先完成待處理的算式）；`[SHIFT][M+]` 為 M−；`[MR]` 讀回 M。M 不為零時 LCD 亮起 M。

常數記憶 K：`[Kin]` 存入，`[Kout]` 讀回（SD／LR 模式下 `Kout` 改為讀統計變數），`[SHIFT][Kout]`（X↔K）把顯示值與 K 互換，`[SHIFT][AC]`（KAC）清除。適合把同一個系數（例如稅率、匯率）反覆代入。

## 十、課堂小提示

用右側「按鍵記錄」逐鍵投影，學生跟按時不會漏步；示範完一題按「清除記錄」再開始下一題。切換模式時，鍵面的橙色 SHIFT 標籤與鍵下小字會即時改變，正好用來說明「同一個鍵在不同模式下做不同的事」——這是學生用實機時最常撞板的地方。
