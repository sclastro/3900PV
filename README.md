# Casio fx-3900PV 網頁模擬器

供課堂投影示範用的 fx-3900PV 模擬計算機。純 HTML／CSS／JavaScript，無需安裝、無需建置、無需網絡——把整個資料夾複製到手指或校內磁碟，雙擊 `index.html` 即可使用。

## 使用方法

用滑鼠按機身按鍵，或用實體鍵盤：

| 實體鍵 | 對應 |
| --- | --- |
| `0`–`9`、`.` | 數字與小數點 |
| `+` `-` `*` `/` | ＋ － × ÷ |
| `Enter` 或 `=` | ＝ |
| `(` `)` | 括號 |
| `Esc` | AC |
| `Backspace` | C |
| `s` | SHIFT |
| `m` | MODE |

右側面板有三項課堂輔助（真機沒有）：**按鍵記錄**逐鍵列出剛才按過的鍵，方便學生跟按；**目前模式鍵義**隨模式即時更新，列出所有 SHIFT 功能；**MODE 對照**列出模式編號。

## 功能

一般計算（COMP）採即時執行加真代數優先次序：按下運算子時會先收斂優先次序不低於它的待處理運算並顯示中間結果，與真機一致。括號最多 6 層；顯示 10 位有效數字加 2 位指數，內部保留 12 位。

- 函數：`sin` `cos` `tan` 及反函數、雙曲函數（`hyp`）、`log` `ln` `10ˣ` `eˣ`、`x²` `√` `xʸ` `ˣ√y` `x⁻¹` `x!`、`π`、亂數、百分比、`ENG`。
- 角度：DEG／RAD／GRA，度分秒輸入與換算。
- 座標轉換：`Pol(` `Rec(`，結果以 `x↔y` 鍵切換。
- 顯示設定：NORM 1／NORM 2、FIX、SCI、`RND`。
- 記憶：獨立記憶 `Min` `MR` `M+` `M−`，常數記憶 `Kin` `Kout`。
- 統計 SD：`n` `Σx` `Σx²` `x̄` `xσn` `xσn−1`，可帶次數輸入，可刪除上一筆或清除全部。
- 迴歸 LR：`A` `B` `r` `x̂` `ŷ` `Σy` `Σy²` `Σxy` 及 x、y 的平均數與標準差。
- 數制 BASE：DEC／HEX／BIN／OCT 互換，32 位二補數，`and` `or` `xor` `xnor` `Not` `Neg`。

詳細操作步驟與課堂示例見 [`docs/操作指南.md`](docs/操作指南.md)。

## 測試

```
node --test tests/*.test.js
```

29 組測試以按鍵序列驅動運算核心（`js/engine.js`），涵蓋運算次序、顯示位數、括號、百分比、函數、記憶、統計、迴歸、數制與錯誤狀態。

## 檔案結構

```
index.html          版面
css/style.css       樣式
js/format.js        顯示格式化（10 位尾數 + 2 位指數、NORM／FIX／SCI／ENG）
js/keypad.js        鍵盤佈局與各模式鍵義
js/engine.js        運算核心（不觸碰 DOM，可在 Node 下測試）
js/ui.js            介面：產生鍵盤、繪 LCD、鍵盤輸入
tests/engine.test.js
docs/操作指南.md
```

`js/engine.js` 不依賴 DOM，可獨立引入：

```js
const { Calculator } = require('./js/engine.js');
const c = new Calculator();
c.run('2 + 3 × 4 =');   // '14.'
```

## 與實機的差異（請先讀）

本模擬器為非官方作品，並無 Casio 授權。**鍵盤佈局、MODE 編號與部分 SHIFT 功能的位置，是按 Casio 同期機種的慣例重建的，未曾逐鍵核對實機**；若讀者手上有實機而發現出入，請以實機為準，亦歡迎開 issue 指正。

已知的刻意取捨：

1. **函數為後置輸入**——先按數值，再按 `sin`、`x²` 等，即 VPAM 之前機種的做法。
2. **未實作分數鍵 `a b/c`**。程式結構已預留，日後可補。
3. **BIN 顯示完整 32 位字串**並自動縮小字級，不做真機的分段捲動。
4. **數字後直接按 `(` 視為乘法**（例如 `3 ( 2 + 4 ) =` 得 18）。
5. **統計資料的輸入分隔用 `SHIFT )`（即 `,`）**，同時亦支援 `x × f DT` 這種舊式帶次數輸入。
6. 亂數 `RAN#` 產生三位小數，與真機同為偽亂數，但數列不相同。
