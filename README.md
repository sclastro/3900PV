# Casio fx-3600Pv 網頁模擬器

供課堂投影示範用的 fx-3600Pv 模擬計算機。純 HTML／CSS／JavaScript，無需安裝、無需建置、無需網絡——把整個資料夾複製到手指或校內磁碟，雙擊 `index.html` 即可使用。

鍵位、模式編號與鍵面標籤依實機照片重建（見下文「與實機的差異」）。

## 使用方法

用滑鼠按機身按鍵，或用實體鍵盤：

| 實體鍵 | 對應 |
| --- | --- |
| `0`–`9`、`.` | 數字與小數點 |
| `+` `-` `*` `/` | ＋ － × ÷ |
| `Enter` 或 `=` | ＝ |
| `(` `)` | `[(` 與 `)]` |
| `Esc` | AC |
| `Backspace` | C |
| `s` | SHIFT |
| `m` | MODE |

右側面板有三項課堂輔助（真機沒有）：**按鍵記錄**逐鍵列出剛才按過的鍵，方便學生跟按；**目前模式鍵義**隨模式即時更新；未實作的鍵按下時會在該處提示。

## MODE 對照（同實機印字）

| 按鍵 | 作用 | | 按鍵 | 作用 |
| --- | --- | --- | --- | --- |
| `MODE ·` | RUN　一般計算 | | `MODE 4` | DEG |
| `MODE EXP` | LRN　程式輸入（未實作） | | `MODE 5` | RAD |
| `MODE 0` | BASE-N　數制運算 | | `MODE 6` | GRA |
| `MODE 1` | ∫dx　積分（未實作） | | `MODE 7` *n* | FIX　固定 *n* 位小數 |
| `MODE 2` | LR　線性迴歸 | | `MODE 8` *n* | SCI　*n* 位有效數字 |
| `MODE 3` | SD　標準差 | | `MODE 9` `1`／`2` | NORM 1／NORM 2 |

## 功能

一般計算採即時執行加真代數優先次序：按下運算子時會先收斂優先次序不低於它的待處理運算並顯示中間結果，與真機一致。括號最多 6 層；顯示 10 位有效數字加 2 位指數，內部保留 12 位。

- 函數：`sin` `cos` `tan` 及反函數、雙曲函數（`hyp`）、`log` `ln` `10ˣ` `eˣ`、`√` `x²` `∛` `xʸ` `x¹ᐟʸ` `1/x` `x!`、`nPr` `nCr`、`π`、`RAN#`、`%`、`ENG`。
- 分數：`a b/c` 輸入帶分數與真分數，`d/c` 切換帶分數與假分數，再按 `a b/c` 可與小數互轉。
- 角度：DEG／RAD／GRA，度分秒輸入與換算。
- 座標轉換：`R→P`（SHIFT ＋）與 `P→R`（SHIFT －），第二個結果按 `X↔Y`（SHIFT Kin）讀取。
- 顯示設定：NORM 1／NORM 2、FIX、SCI、`RND`。
- 記憶：獨立記憶 `Min` `MR` `M+` `M−`；常數記憶 `Kin` `Kout` `X↔K`，`KAC` 清除。
- 統計 SD：輸入 `x [RUN]`，帶次數 `x [×] 次數 [RUN]`；`DEL` 刪去上一筆。
- 迴歸 LR：輸入 `x [×] y [RUN]`；可取 A、B、r、x̂、ŷ 及各項總和。
- 數制 BASE-N：DEC／HEX／BIN／OCT 互換，32 位二補數，`AND` `OR` `XOR` `XNOR` `NOT` `NEG`；十六進 A–F 在 `+/−` 至 `tan` 一整行。

### 統計變數的讀取

數字鍵下方的方括號標籤即統計變數，**`Kout` + 數字鍵**讀左邊一個，**`SHIFT` + 數字鍵**讀右邊一個：

| 鍵 | `Kout` + 鍵 | `SHIFT` + 鍵 |
| --- | --- | --- |
| `1` | x̄ | Σx² |
| `2` | xσn | Σx |
| `3` | xσn−1 | n |
| `4` | ȳ | Σy² |
| `5` | yσn | Σy |
| `6` | yσn−1 | Σxy |
| `7` `8` `9` | A、B、r | — |
| `)]` | ŷ | x̂ |

詳細操作步驟與課堂示例見 [`docs/操作指南.md`](docs/操作指南.md)。

## 測試

```
node --test tests/*.test.js
```

29 組測試以按鍵序列驅動運算核心（`js/engine.js`），涵蓋運算次序、顯示位數、括號、百分比、分數、函數、記憶、統計、迴歸、數制與錯誤狀態。

## 檔案結構

```
index.html          版面
css/style.css       樣式
js/format.js        顯示格式化（10 位尾數 + 2 位指數、NORM／FIX／SCI／ENG）
js/keypad.js        鍵盤佈局與各模式鍵義
js/engine.js        運算核心（不觸碰 DOM，可在 Node 下測試）
js/ui.js            介面：產生鍵盤、繪 LCD、鍵盤輸入
tests/engine.test.js
docs/操作指南.md
```

`js/engine.js` 不依賴 DOM，可獨立引入：

```js
const { Calculator } = require('./js/engine.js');
const c = new Calculator();
c.run('2 + 3 × 4 =');   // '14.'
```

## 與實機的差異（請先讀）

本模擬器為非官方作品，並無 Casio 授權。鍵位、MODE 編號與鍵面標籤依一張實機照片重建，機身印字（MODE 對照條、A–F、AND／OR／XOR／XNOR／NOT／NEG、統計變數的方括號標籤）已逐一核對，但仍有未能核實之處：

1. **統計變數的讀取方式**是本模擬器最不確定的一點。照片只顯示數字鍵 1–6 下方各有兩組方括號標籤，未能看出兩組分別用什麼前綴叫出。這裡採用 `Kout` + 數字鍵取左邊、`SHIFT` + 數字鍵取右邊；若與實機不符，改 `js/keypad.js` 的 `KOUT_STAT` 與各鍵 `shiftAction` 即可。
2. **LR 的資料輸入**採 `x [×] y [RUN]`，SD 帶次數採 `x [×] 次數 [RUN]`，此為同期 Casio 機種的慣例，未在照片中得到確認。
3. **程式功能未實作**：`P1`、`P2`、`LRN`、`PCL`、`RUN`（執行）、`x>0`、`x≧M`、`RTN`、`ENT`、`HLT`，以及 `MODE 1` 的積分 `∫dx`。鍵位照畫，按下會提示未實作。
4. **函數為後置輸入**——先按數值，再按 `sin`、`√` 等，即 VPAM 之前機種的做法。
5. **BIN 顯示完整 32 位字串**並自動縮小字級，不做真機的分段捲動。
6. **數字後直接按 `[(` 視為乘法**（例如 `3 [( 2 + 4 )] =` 得 18）。
7. 亂數 `RAN#` 產生三位小數，與真機同為偽亂數，但數列不相同。

倉庫名為 `3900PV`（最初以 fx-3900PV 為題），內容則按實機照片改為 fx-3600Pv。
